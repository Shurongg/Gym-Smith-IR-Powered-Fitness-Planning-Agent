# Progression Rules

## Progressive overload
Every workout plan should include one progression method:
- add 1–2 reps
- add a small amount of weight
- add one set
- improve control and range of motion
- reduce excessive rest slightly
- move to a harder variation

## Conservative default
If user is beginner or training status unknown:
- Do not increase load every session by default.
- Prefer rep progression first.
- Increase load only when the user can complete all sets at the top of the rep range with good form.

## Load increase rule
If using external weight:
- Increase load by a small amount only after the user exceeds the target rep range with good form.
- Avoid aggressive jumps.

## 8-week plan rule
For an 8-week plan:
- Weeks 1–2: learning and baseline volume
- Weeks 3–5: gradual overload
- Week 6: maintain or slightly increase difficulty
- Week 7: hardest normal week
- Week 8: review, repeat, or deload depending on fatigue

## Fatigue rule
If user reports:
- persistent soreness
- performance drop
- poor sleep
- joint discomfort
- loss of motivation

Then reduce one of:
- sets
- load
- intensity
- session length
