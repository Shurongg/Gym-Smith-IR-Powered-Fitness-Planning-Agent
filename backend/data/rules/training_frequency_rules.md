# Training Frequency Rules

## Default adult baseline
If the user only asks for general fitness:
- Recommend at least 2 strength-training days per week.
- Cover major muscle groups across the week:
  - legs
  - hips
  - back
  - abdomen/core
  - chest
  - shoulders
  - arms

## If user is beginner
If training experience is unknown or beginner:
- Prefer 2–3 training days per week.
- Prefer full-body or simple upper/lower structure.
- Avoid very high weekly volume.
- Avoid advanced intensity techniques.

## If user requests 3 days per week
Use one of these structures:
- Full body × 3
- Push / Pull / Legs
- Upper / Lower / Target-focus
- Goal-specific split, if target muscle is clear

## If user requests arm definition
Use 3-day structure:
- Day 1: push + triceps
- Day 2: pull + biceps
- Day 3: arms + shoulders + core

## If user requests chest and abs
Use 3-day structure:
- Day 1: chest emphasis + core
- Day 2: full body or upper body support
- Day 3: chest accessory + core

## Rest rule
Avoid hard training of the same target muscle on consecutive days unless the plan uses very low volume or technique practice.
