# Output Constraints

## Every workout plan must include
1. Goal summary
2. Assumptions
3. Weekly schedule
4. Exercises with sets/reps/rest/equipment
5. Progression rule
6. Basic nutrition notes
7. Safety note
8. Optional alternatives

## Do not include
- guaranteed visual results
- medical claims
- injury treatment
- extreme dieting
- supplement prescriptions
- advanced bodybuilding techniques unless requested

## If information is missing
If equipment is missing:
- Ask one clarification question, or provide a bodyweight/dumbbell fallback.

If training frequency is missing:
- Default to 3 days per week.

If intensity is missing:
- Default to moderate intensity.

If experience level is missing:
- Default to beginner/intermediate conservative plan.

## Tone
Use practical, direct wording.
Avoid motivational exaggeration.
